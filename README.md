# أركيدو (Arcado) — منصة ألعاب السهرة العربية

منصة ألعاب اجتماعية عربية تحاكي برامج المسابقات التلفزيونية داخل البيوت.

## 🎮 لعبة "من سيربح الجائزة" — تعمل بالوقت الفعلي (مباشر)

سيرفر Node + Socket.IO يربط التلفزيون + المضيف + جوالات اللاعبين لحظياً، مع باركود QR حقيقي وبنك أسئلة.

```bash
npm install
npm start
# ثم افتح:
#   المضيف:    http://localhost:3000/host.html
#   التلفزيون: http://localhost:3000/tv.html
#   اللاعب:    يمسح الباركود من شاشة المضيف (أو play.html)
```

**طريقة اللعب:** المضيف يفتح جلسة → يظهر رمز + باركودان (أخضر/أحمر) → التلفزيون يدخل الرمز → اللاعبون يمسحون باركود فريقهم → المضيف يبدأ → الأسرع ضغطاً على Buzz يجاوب → المضيف يحكم صح/خطأ → النقاط تتحدّث لحظياً.

### بنك الأسئلة الذكي (`server/qbank.js` + `server/progress.js`)
- **توزيع متساوٍ:** كل جولة تأخذ عدداً متساوياً من كل قسم من الأقسام الخمسة.
- **آلة حاسبة:** عدد الأسئلة = (عدد لاعبي أكبر فريق) × (عدد الأقسام). مثال: فريق من 4 → 20 سؤالاً (4 من كل قسم).
- **ذاكرة لكل لاعب:** كل جلسة تجلب أسئلة لم تمرّ عليه من قبل، حتى يُستنفد البنك (500 سؤال).
- **أولوية المراجعة:** عند إعادة تدوير البنك، الأسئلة التي أُجيب عنها **خطأً** (لم تثبت) تظهر أولاً.
- التخزين دائم في `data/progress.json` (مفتاحه `playerId` = License Key مستقبلاً).

### الاختبارات
- محرّك اللعبة (آلة حالة خالصة قابلة للاختبار)
- بنك الأسئلة الذكي: 4 متطلبات (توزيع/حاسبة/ذاكرة/أولوية) مُختبرة ✓
- اختبارات E2E عبر السوكِت تشمل استمرار الذاكرة عبر الجلسات ✓

