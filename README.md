# أركيدو (Arcado) — واجهات المنصة

منصة ألعاب اجتماعية عربية تحاكي برامج المسابقات التلفزيونية داخل البيوت.
هذا المستودع يحتوي على **واجهات المنصة (Mockups)** — HTML/CSS/JS صرف، بدون سيرفر وبدون خطوة بناء.

## كيف تشغّلها

افتح `public/index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
cd public
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## محتوى الواجهات

| الشاشة | الملف |
| --- | --- |
| الصفحة الرئيسية + الترخيص + اختيار اللعبة | `public/index.html` |
| **من سيربح الجائزة** — تلفزيون / مضيف / جوال | `millionaire-tv.html` · `millionaire-host.html` · `millionaire-play.html` |
| **حروف** — تلفزيون / مضيف / جوال | `huroof-tv.html` · `huroof-host.html` · `huroof-play.html` |
| **طيف** — تلفزيون / مضيف / جوال | `taif-tv.html` · `taif-host.html` · `taif-play.html` |
| **ديكربتو** — تلفزيون / مضيف / جوال | `decrypto-tv.html` · `decrypto-host.html` · `decrypto-play.html` |

كل لعبة موزّعة على ثلاث شاشات: 📺 التلفزيون (عامة) · 🎛️ المضيف (سرية) · 📱 الجوال (وحدة تحكم اللاعب).

## الهوية البصرية

الألوان مأخوذة حرفياً من وثيقة المشروع:

- **المنصة:** أحمر `#FF3F33` · وردي فاتح `#FFE6E1` · أخضر داكن `#075B5E` · أخضر فاتح `#9FC87E`
- **من سيربح الجائزة:** `#59B292` `#FFC94D` `#FAE7CB` `#FA6781`
- **حروف:** `#427AB5` `#406AAF` `#F7DD7D` `#FFE8BE`
- **طيف:** `#A8DF8E` `#F0FFDF` `#FFD8DF` `#FFAAB8`
- **ديكربتو:** `#000000` `#9929EA` `#FF5FCF` `#FAEB92`

## البنية

```
public/
├── index.html              # المنصة الرئيسية + فهرس الشاشات
├── css/
│   ├── theme.css           # الهوية، RTL، المكوّنات العامة
│   └── games.css           # لوحات ألوان الألعاب ومكوّناتها (الباركود، اللوحة السداسية، المقياس، جدول التلميحات)
├── js/
│   └── demo.js             # تفاعلات بسيطة للمعاينة (باركود زخرفي، عدّاد، وميض Buzz، مؤشر طيف)
└── *.html                  # شاشات الألعاب الـ12
```

## ملاحظات

- هذه **واجهات تصميمية للمعاينة** بمعطيات تجريبية — منطق الوقت الفعلي (Socket/Buzz)
  ونظام التراخيص وبنك الأسئلة الكامل تأتي في مرحلة لاحقة (راجع البند ٨ من الوثيقة: ما يحتاج تحديد لاحقاً).
- الباركود المعروض **زخرفي** لغرض العرض فقط.
